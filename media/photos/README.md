# Photos (v1)

Store approved public-facing photo files here.

## Naming

`YYYY-MM-DD-short-title.ext`

Examples:
- `2026-08-13-first-day-mvhs.jpg`
- `2026-10-01-science-fair.png`

## Rules

- Only include images that are approved for public display
- Avoid sensitive or private background information
- Prefer compressed web-friendly image formats
