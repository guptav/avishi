# avishi

Avishi Gupta's **High School & Graduate Journey** website.

This repository hosts a lightweight, public-facing static site that starts with Avishi's Monta Vista High School journey and is designed to grow into later graduate milestones.

## Quick Start

Open `/home/runner/work/avishi/avishi/index.html` in any browser.

## Repository Structure

- `/home/runner/work/avishi/avishi/index.html` — main site page
- `/home/runner/work/avishi/avishi/assets/css/styles.css` — responsive design system and layout
- `/home/runner/work/avishi/avishi/assets/js/site.js` — timeline rendering and filters
- `/home/runner/work/avishi/avishi/content/milestones.json` — milestone data model and entries
- `/home/runner/work/avishi/avishi/docs/GOVERNANCE.md` — edit/publish roles, review flow, privacy boundaries
- `/home/runner/work/avishi/avishi/docs/CONTENT_WORKFLOW.md` — editorial standards and publishing workflow
- `/home/runner/work/avishi/avishi/docs/QUALITY_AND_ROADMAP.md` — quality, safety checks, launch roadmap

## Content Updates

1. Add or update entries in `/home/runner/work/avishi/avishi/content/milestones.json`.
2. Keep required fields (`id`, `date`, `title`, `category`, `status`, `description`) complete.
3. Follow editorial and privacy guidance in docs before publishing.
