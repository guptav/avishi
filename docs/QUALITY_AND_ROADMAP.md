# Quality, Compliance, and Roadmap

## Quality and Safety Checks

### Accessibility Baseline (Markdown/GitHub Pages)

- Use logical heading order
- Use descriptive link text
- Keep tables readable and concise
- Avoid emoji-only meaning for critical content

### Link and Content Integrity

- Verify every new external link opens correctly
- Prefer official sources for school/program references
- Confirm dates and milestone facts before publication

### Privacy and Safety

- Exclude sensitive personal details
- Share only approved public-facing evidence
- Redact or omit uncertain private information

### Durability and Recovery

- Keep all changes in git history
- Use tagged snapshots at major milestones (v1, v1.1, v2)
- Retain archived milestones in Markdown for continuity
